【ファイルのパス】
工夫した点

振る動作の判定は、加速度の大きさだけで判定すると、歩いたり持ち替えたりしただけで反応してしまいます。 そこで【実際にやった対策】で誤判定を減らし、「振って壊す」爽快感が出るように調整しました。

チーム制作について

6人チームのリーダーとして、意見をまとめて制作を進めることに一番苦労しました。 自分の当たり前が相手の当たり前とは限らないと気づき、「こうしたい」の後に必ず理由を添えて伝えるようにしました。
